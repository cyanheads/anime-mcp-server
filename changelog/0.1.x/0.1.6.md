# 0.1.6 — 2026-08-30

## Changed

- **`anime_find_characters` and `anime_get_recommendations`** now include the next page and repeated inputs when a result page is capped ([#15](https://github.com/cyanheads/anime-mcp-server/issues/15)).
- **`.env.example`** now enables `MCP_SESSION_MODE=stateless` as the active sample setting ([#17](https://github.com/cyanheads/anime-mcp-server/issues/17)).

## Fixed

- **Declared tool errors** from character, media, relation, schedule, and studio lookups now include their recovery hint on both MCP error surfaces ([#14](https://github.com/cyanheads/anime-mcp-server/issues/14)).

## Dependencies

- `@biomejs/biome` ^2.5.9 → ^2.5.11; `@types/node` ^26.2.0 → ^26.4.0.
