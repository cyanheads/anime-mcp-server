# 0.1.2 — 2026-06-06

## Fixed

- **`anime_search_media`, `anime_get_rankings`, `anime_get_schedule`** — empty-result paths now call `ctx.enrich.notice()`, populating `structuredContent.notice` with the applied filters and a recovery suggestion (#1)
- **`anime_get_recommendations`** — removed audience-leaking phrase from `liked_aspects` description; now reads neutrally as caller documentation (#2)
- **`anime_get_media`** — `scores` output description rewritten to describe the data (AniList 0–100, MAL 0–10.0) rather than coach the consumer (#3)
- **`anime_search_media`** — removed internal routing detail ("AniList is the primary source; Jikan is used as a fallback") from tool description (#4)
- **`anime_get_studio`** — `missing_identifier` added to errors contract; throw switched from `validationError()` to `ctx.fail('missing_identifier', …)` so `data.reason` is populated (#5)
