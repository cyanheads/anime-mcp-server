# 0.1.8 — 2026-09-19

## Changed

- **HTTP session mode** HTTP defaults to stateless when MCP_SESSION_MODE is unset; explicit stateful or auto values still override it. ([#17](https://github.com/cyanheads/anime-mcp-server/issues/17))
- **Framework adoption** updates `@cyanheads/mcp-ts-core` to `^0.13.6`, serving client-visible `InvalidParams` argument envelopes, recovery hints, known client-added key aliases and stringified-array normalization, and reason or retryable error text; nullable output schemas render as equivalent type arrays.
- **Runtime floor** requires Bun `>=1.4.0`.
- **Project skills** move to `framework-skills/` and packaging checks cover the synchronized plugin manifests.

## Fixed

- **AniList and Jikan requests** use framework pacers that dispose on shutdown; Jikan 5xx responses remain non-retryable.
- **`anime_find_characters`** forwards its `missing_identifier` recovery hint.

## Security

- **AniList description normalization** decodes nested HTML entity references only once. ([#28](https://github.com/cyanheads/anime-mcp-server/issues/28))
