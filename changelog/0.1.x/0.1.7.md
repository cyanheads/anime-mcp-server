# 0.1.7 — 2026-08-30

## Fixed

- **AniList descriptions** now return normalized full synopsis and staff-bio text, while rendered output stays bounded. [#7](https://github.com/cyanheads/anime-mcp-server/issues/7)
- **`anime_search_media`** accepts only documented sort values and maps Jikan fallback matches to actionable AniList IDs. [#8](https://github.com/cyanheads/anime-mcp-server/issues/8) [#9](https://github.com/cyanheads/anime-mcp-server/issues/9)
- **`anime_find_characters`** forwards pagination for character appearances, returns their media context, and reports a typed not-found error for an invalid media ID. [#10](https://github.com/cyanheads/anime-mcp-server/issues/10) [#11](https://github.com/cyanheads/anime-mcp-server/issues/11)
- **`anime_get_recommendations`** reports a typed not-found error when the source AniList ID is absent. [#12](https://github.com/cyanheads/anime-mcp-server/issues/12)
- **`anime_get_schedule`** filters adult upcoming titles by default and preserves the upstream next-page signal after filtering. [#13](https://github.com/cyanheads/anime-mcp-server/issues/13)
