# 0.1.3 — 2026-06-11

## Added

- **`scripts/clean-mcpb.ts`** — post-pack bundle cleaner wired into the `bundle` script after `mcpb pack`: runs `mcpb clean` (dev-dependency prune + manifest validation), then strips `node_modules/**` agent-doc entries (`skills/`, `.claude/`, `.agents/` trees and `SKILL.md` files) that root-anchored `.mcpbignore` patterns cannot reach.
- **`lint:packaging` bundle-content and identity checks** — guards that a built `.mcpb` carries no `node_modules/**` agent-doc entries, that `.mcpbignore` dev-dir patterns stay root-anchored (so they can't strip nested runtime paths), and that the `createApp()` `name`/`title` pair matches the unscoped package name.
- **`coerce-boolean-env-flag` antipattern rule** (`scripts/check-framework-antipatterns.ts`, run by `devcheck`) — flags `z.coerce.boolean()` on env flags, which can't be disabled through the environment; the scanner now skips comment lines so docs naming the pattern don't false-positive.

## Changed

- **`createApp()` identity** — explicit `name: 'anime-mcp-server'` and `title: 'anime-mcp-server'` set in `src/index.ts`, populating `initialize` serverInfo and `/.well-known/mcp.json` with the hyphenated server name rather than relying on the scoped-package fallback.
- **`anime_get_studio`, `anime_find_characters`, `anime_get_schedule`** — the `missing_identifier` / `invalid_season` error contracts recoded from `InvalidParams` (-32602) to `ValidationError` (-32007), the framework's baseline code for invalid input combinations.
- **`.mcpbignore`** — dev-dir patterns re-anchored to root (`/.claude/`, `/.agents/`, `/skills/`) so they exclude only the project's own trees, not nested `node_modules` runtime paths.
- Dependencies: `@cyanheads/mcp-ts-core` `^0.9.21 → ^0.10.6`, `@types/node` `^25.9.2 → ^25.9.3`.
