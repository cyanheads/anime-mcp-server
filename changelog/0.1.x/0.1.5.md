# 0.1.5 — 2026-08-21

## Fixed

- **`anime_find_characters` name-based lookups return results again** — `truncated` / `shown` / `cap` were declared as required enrichment but written only in the media-ID mode, so a `character_name` or `voice_actor_name` call failed output validation instead of returning its match. The three fields are now optional and present only when the cast list was capped.
- **Truncation is disclosed only when a page was capped** — `anime_find_characters` (by_media mode) and `anime_get_recommendations` set `truncated: true` on every call, including complete result sets. Both now disclose it only when the source reports a further page.
