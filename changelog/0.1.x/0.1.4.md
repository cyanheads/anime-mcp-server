# 0.1.4 — 2026-08-21

## Added

- **`totalCount` enrichment** — `anime_search_media`, `anime_get_rankings`, `anime_get_schedule` (season mode), `anime_get_studio`, and `anime_get_relations` disclose the total matching entries when the source reports it, alongside the paged results.
- **Truncation disclosure** — `anime_find_characters` (by_media mode) and `anime_get_recommendations` return `truncated` / `shown` / `cap` enrichment when a page was capped at `per_page`.
- **`.github/` community-health files** — CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, and FUNDING.

## Changed

- **Framework adoption: `@cyanheads/mcp-ts-core` `^0.10.6 → ^0.12.3`** — MCP SDK v2; every endpoint serves protocol revision 2026-07-28 alongside the 2025 era; tool inputs are strict (an unrecognized argument key is rejected by name); the advertised `outputSchema` declares the error envelope; schemas advertise JSON Schema 2020-12. This server's tool contracts are unchanged.
- **`anime_get_schedule` text output** renders the `mode:` discriminator in both headers, matching the structured output.
- **Docker image** — production stage omits optional peer tiers (`--omit=peer`), adds a `/healthz` HEALTHCHECK and BuildKit cache mounts; build stage pinned to the caller's platform so multi-arch builds don't run Bun under QEMU.
- **Supply-chain guard** — `bunfig.toml` blocks packages published less than 3 days ago (`minimumReleaseAge`) and runs the Socket security scanner on install.

## Fixed

- **`anime_find_characters`** — name-based lookup without `voice_actor_name` now throws the declared `missing_identifier` contract error instead of forwarding `undefined` upstream.

## Dependencies

- `@cyanheads/mcp-ts-core` `^0.10.6 → ^0.12.3`
- `typescript` `^6.0.3 → ^7.0.2`, `@types/node` `^25.9.3 → ^26.2.0`, `@biomejs/biome` `^2.4.16 → ^2.5.9`, `vitest` `^4.1.8 → ^4.1.11`, `tsc-alias` `^1.8.17 → ^1.9.2`, `ignore` `^7.0.5 → ^7.0.6`; `@socketsecurity/bun-security-scanner` `^1.1.2` added; `packageManager` `bun@1.3.11 → bun@1.4.0`
