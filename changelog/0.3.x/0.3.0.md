# 0.3.0 — 2026-10-13

## Changed

- **`relation_to_root`** now describes direct root edges only; deeper entries use null and expose `depth`, `parent_id`, `relation_to_parent`, and `path`. Ordering is a relation-priority/year heuristic. ([#18](https://github.com/cyanheads/anime-mcp-server/issues/18))
- **Resource IDs** require the complete SDK-parsed segment to contain ASCII decimal digits representing 1–2147483647; numeric-prefix aliases are rejected. Leading zeros remain accepted; SDK URL whitespace normalization precedes validation. ([#23](https://github.com/cyanheads/anime-mcp-server/issues/23))
- **Framework input repair** accepts numeric-string `page`/`per_page`/`id`, boolean strings, lone-string sort lists, and null optional fields through `@cyanheads/mcp-ts-core` 0.13.15.
- **Development guidance** synchronizes framework skills and Bun 1.4.3 pins.

## Fixed

- **`anime_get_relations`** returns only nodes within `max_depth`, avoids boundary-node fetches, and retains first shortest BFS discovery paths through cycles and shared descendants. ([#18](https://github.com/cyanheads/anime-mcp-server/issues/18))
- **Text retrieval** adds `full_text` to media and characters for complete domain JSON on the current page; bounded summaries disclose exact omissions and escape provider Markdown/HTML without altering structured values. ([#19](https://github.com/cyanheads/anime-mcp-server/issues/19))
- **`anime_find_characters`** pairs each appearance's media, role, and actors from one edge; `voice_actor_data_available` distinguishes unavailable actor data from a genuine empty list. ([#27](https://github.com/cyanheads/anime-mcp-server/issues/27))
- **Optional enums** accept exact blank form sentinels as absent; search sort drops blank items and blank studio sort uses `POPULARITY_DESC`. ([#33](https://github.com/cyanheads/anime-mcp-server/issues/33))
- **AniList tool IDs** reject values above GraphQL Int's 2147483647 ceiling before upstream work. ([#34](https://github.com/cyanheads/anime-mcp-server/issues/34))
- **MANGA rankings** reject seasonal mode and meaningful season/year filters with `anime_only_season` recovery guidance. ([#35](https://github.com/cyanheads/anime-mcp-server/issues/35))
- **Upcoming schedules** request AniList `TIME` ordering before pagination, retaining upstream pagination after adult filtering. ([#36](https://github.com/cyanheads/anime-mcp-server/issues/36))
