# 0.4.0 — 2026-10-30

## Added

- **`anime-guide` resource** at `skill://anime-guide/SKILL.md` guides franchise, cast, studio, schedule, and recommendation research; also delivered through plugin, npm, Docker, and MCPB installs.
- **`anime_get_recommendations`** accepts additive `source: "anilist" | "jikan"`, defaults to AniList, and returns `source` and `jikan_status`. Jikan candidates are deduplicated by maximum votes, locally paged, then resolved through AniList without blending ratings. ([#22](https://github.com/cyanheads/anime-mcp-server/issues/22))

## Changed

- **Packaging and development tooling** synchronize framework skills, Agent Plugins metadata, published-skill validation, audit attribution, and bundle cleanup; SDK runtime skill modules remain in bundles while dependency development files are removed.
- **Install age guard** uses a one-day minimum release age.

## Fixed

- **Tool summaries** render provider prose at interpolation boundaries and URLs as links or images, preserving punctuation, URL destinations, structured values, and lossless full-text JSON. ([#40](https://github.com/cyanheads/anime-mcp-server/issues/40))
- **Recommendations** retain AniList results when optional Jikan annotations fail, report availability, and propagate cancellation through lookup, pacing, retries, and resolution under one operation deadline. Selected-source failures provide retry-or-switch guidance. ([#22](https://github.com/cyanheads/anime-mcp-server/issues/22))
