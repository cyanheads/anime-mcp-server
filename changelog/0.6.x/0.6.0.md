# 0.6.0 — 2026-11-20

## Added

- **`anime_get_media`** returns AniList manga reading links by language. The compact media resource counts the same links. (#58)

## Changed

- Adult media cast lookups now require `include_adult: true` in `anime_find_characters`. (#52)
- **`anime_get_schedule`** describes `season` as the premiere-season catalog and points to `upcoming` for episodes from continuing series. (#54)

## Fixed

- **Adult credits** are hidden by default from studio filmographies, character appearances, and voice roles. Mixed upcoming pages report how many adult episodes they omit. (#52)
- **MyAnimeList fallback** uses resolved AniList metadata with Jikan order and pagination. It reports omitted rows and gives next-page guidance even when no row on the current page resolves. (#53)
- **`anime_get_relations`** orders entries by release date within each existing group. (#55)
- **`anime://media/{id}`** reports source flags and names failed Jikan or Kitsu requests. (#56)

- `ignore` ^7.0.14 → ^7.0.16
