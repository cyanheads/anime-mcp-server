# 0.5.0 — 2026-11-13

## Added

- **`anime_search_media`** accepts `start_year` for anime and manga, including entries with partial release dates. Successful and empty results echo normalized criteria in `effectiveQuery`. ([#42](https://github.com/cyanheads/anime-mcp-server/issues/42))
- **Media metadata** includes release dates at their known precision, episode duration, origin, alternate titles, and supported trailers. Search accepts `country_of_origin`, and search, rankings, and relation rows expose it. ([#46](https://github.com/cyanheads/anime-mcp-server/issues/46))
- **`anime_find_characters`** accepts exact character and staff IDs, offers first-page name suggestions with continuation independent of role paging, and includes the selected character's biography. ([#47](https://github.com/cyanheads/anime-mcp-server/issues/47))
- **`anime_get_studio`** accepts `main_only` for both name and ID lookups. AniList filters the credits before pagination, and `total_titles` is exact only when the filmography fits on page one. ([#48](https://github.com/cyanheads/anime-mcp-server/issues/48))
- **`include_adult`** opts into adult titles in relations and recommendations. Both recommendation sources expose `is_adult`. ([#44](https://github.com/cyanheads/anime-mcp-server/issues/44))

## Changed

- **Upstream HTTP failures no longer include captured response bodies in tool errors:** `structuredContent.error.data.body` and `responseBody` remain server-side.
- **`anime_find_characters`** defaults to 10 entries in every lookup mode. The maximum is 25, and cast results retain actor URLs and all returned languages by default. ([#49](https://github.com/cyanheads/anime-mcp-server/issues/49))

## Fixed

- **Search and rankings** suggest matching AniList tags when an invalid genre produces an empty first page. Manga search rejects anime broadcast-season filters with `anime_only_season`. ([#42](https://github.com/cyanheads/anime-mcp-server/issues/42))
- **Streaming destinations** merge Kitsu and enabled AniList links by hostname, retaining Kitsu's language metadata for duplicate hosts. The media resource counts the same list. ([#43](https://github.com/cyanheads/anime-mcp-server/issues/43))
- **Adult title handling** distinguishes adult roots from missing IDs. Without opt-in, media detail, relation traversal, and recommendations omit adult entries. The compact resource excludes adult roots. ([#44](https://github.com/cyanheads/anime-mcp-server/issues/44))
- **Optional upstream lookups** preserve primary results on timeouts, malformed payloads, and unavailable annotations. Media supplements and title-only fallback each get one five-second budget with no retries. Caller cancellation propagates. ([#45](https://github.com/cyanheads/anime-mcp-server/issues/45))
- **Airing summaries** show minutes below an hour and upcoming schedule rows include total episodes when known. ([#50](https://github.com/cyanheads/anime-mcp-server/issues/50))
