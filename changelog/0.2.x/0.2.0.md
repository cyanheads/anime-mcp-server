# 0.2.0 — 2026-09-24

Migration: calls that used to succeed now fail with a `ValidationError` (blank-only searches, conflicting multi-mode inputs, seasonal rankings with one of `season`/`season_year`, studio `per_page` above 25), and `total_results`/`total_titles` are `null` wherever they used to carry AniList's placeholder total. Paginate on `has_next_page`.

## Added

- **`anime_get_rankings` `tag`** filters rankings by AniList tag name in every mode. ([#24](https://github.com/cyanheads/anime-mcp-server/issues/24))
- **`anime_get_studio` `is_main_studio`** marks whether the studio holds a main-studio credit on each title. ([#31](https://github.com/cyanheads/anime-mcp-server/issues/31))

## Changed

- **`anime_search_media`** fails `missing_criteria` when no criterion remains; blank `query`/`genre`/`tag` count as absent, and a sort other than `SEARCH_MATCH` alone browses the catalog. The default sort is `POPULARITY_DESC` without a `query`. ([#20](https://github.com/cyanheads/anime-mcp-server/issues/20))
- **Multi-mode inputs** fail `conflicting_inputs` instead of resolving by precedence: `anime_find_characters` takes exactly one of `id`/`character_name`/`voice_actor_name` (`language` only with `id`), `anime_get_studio` one of `id`/`name`, and `anime_get_schedule` rejects the other mode's fields. `anime_get_rankings` seasonal mode fails `invalid_season` with only one of `season`/`season_year`. ([#25](https://github.com/cyanheads/anime-mcp-server/issues/25))
- **Result counts** (`total_results`, `total_titles`, `totalCount`) are exact or `null`: set only on a final page (0 for an empty first page), with a notice on an empty page past the end. ([#26](https://github.com/cyanheads/anime-mcp-server/issues/26))
- **`anime_get_studio` `per_page`** maximum is 25, AniList's page size for a studio's titles. ([#31](https://github.com/cyanheads/anime-mcp-server/issues/31))

## Fixed

- **MyAnimeList fallback** in `anime_search_media` runs only for a title-only query AniList has no match for, honors `include_adult`, is skipped with a notice above `per_page` 25, and degrades to a notice when Jikan fails. ([#21](https://github.com/cyanheads/anime-mcp-server/issues/21), [#32](https://github.com/cyanheads/anime-mcp-server/issues/32))
- **AniList page-depth refusal** (past the first 5,000 entries) surfaces as `page_depth_exceeded` with a recovery hint instead of a raw 400; the last reachable page carries a notice. ([#30](https://github.com/cyanheads/anime-mcp-server/issues/30))
- **`anime_get_studio` filmography** returns one row per distinct title on a page. ([#31](https://github.com/cyanheads/anime-mcp-server/issues/31))

## Dependencies

- `@types/node` (dev) `^26.6.1` → `^26.6.2`
