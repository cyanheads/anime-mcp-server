# 0.2.1 — 2026-10-07

## Changed

- **Tool errors** carry a generated `data.requestId` matching the call's logs and text suffix; the JSON-RPC response retains the caller's ID. Framework-added `data.rootCause` stays off error envelopes.
- **Recovery hints** resolve from declared error contracts at the framework boundary, replacing redundant handler forwarding.
- **Development guidance** and checks follow the current framework; the capability reference is shorter and documents failed-call logging controls.

## Fixed

- **MCP Registry launches** invoke the package bin through `npx`; the HTTP entry fixes `MCP_TRANSPORT_TYPE=http` instead of passing ignored npm-script arguments.
- **Multi-arch Docker builds** install target-platform dependencies on the native build platform, install telemetry peers at framework ranges, and prune unused musl packages.
- **Distribution exclusions** keep `.mcpb` bundles out of npm tarballs and cache, logs, env files, and registry credentials out of build artifacts.
